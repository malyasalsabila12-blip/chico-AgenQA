# Skill: Synthetic Data Generation (Data Factory)

## Purpose
Generate realistic, high-quality test data for automation scripts to ensure broad coverage and avoid hardcoded values.

## Capabilities
- **Identity Generation**: Mocks for Names, Emails, Phone Numbers.
- **Financial Mocks**: Credit card formats, Transaction IDs.
- **Bulk Data**: JSON/CSV generation for performance and load testing.
- **Boundary Values**: Generation of edge-case inputs (e.g., max string lengths, special characters).

## Usage
Invoke this skill when setting up `Preconditions` or `Test Data` sections of a Test Case to get fresh, randomized data sets.

# QA Test Plan Skill

## Kapan Digunakan
Gunakan skill ini ketika ada requirement baru atau perubahan fitur untuk merancang rencana pengujian yang komprehensif.

## Langkah-langkah
1. Baca dan pahami dokumen requirement.
2. Identifikasi skenario positif dan negatif.
3. Tentukan prioritas pengujian.
4. Susun daftar test case.

## Contoh Output
### Test Plan: Fitur Login
- **Scenario 1**: Login dengan kredensial valid (Positif).
- **Scenario 2**: Login dengan password salah (Negatif).
- **Scenario 3**: Login dengan email tidak terdaftar (Negatif).

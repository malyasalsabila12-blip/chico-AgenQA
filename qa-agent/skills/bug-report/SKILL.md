# Bug Report Skill

## Kapan Digunakan
Gunakan skill ini untuk melaporkan temuan bug selama proses pengujian agar informasi yang diberikan konsisten dan jelas.

## Langkah-langkah
1. Tulis judul bug yang ringkas dan deskriptif.
2. Tentukan tingkat keparahan (severity).
3. Berikan langkah-langkah reproduksi.
4. Lampirkan bukti (screenshot/video).

## Contoh Output
### [BUG] Tombol Login Tidak Merespon
- **Severity**: High
- **Steps**:
  1. Buka aplikasi.
  2. Masukkan email dan password.
  3. Klik tombol Login.
- **Expected**: Masuk ke Dashboard.
- **Actual**: Tidak ada respon.
- **Evidence**: [link-to-screenshot.png]
